# 用户指南

## 1. 运行与导航

在项目根目录执行 `python -m sdes_app`。新环境先执行 `python -m pip install -r requirements.txt`。

需要隔离依赖时，可直接使用虚拟环境中的 Python，无需激活脚本：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m sdes_app
```

左侧选择功能页，也可用上下方向键切换。Tab 导航保留轻量蓝色焦点提示；鼠标点击以背景变化反馈。窗口最小尺寸为 880 × 600，页面和长表格可以滚动。窄窗口中交叉表支持横向滚动，表头固定在顶部；长密钥列表自动换行。二进制输入保留前导零；通用格式提示放在悬停提示中，错误直接显示在输入旁。

## 2. 二进制加解密

1. 输入恰好 8 位的分组和恰好 10 位的密钥，只使用 `0`、`1`。首尾空白允许去除，内部空白不接受。
2. 点击“加密”或“解密”。输入框内按 Enter 默认执行加密。
3. 点击结果右上角“复制”复制完整位串。
4. 展开计算步骤查看 P10、各轮累计移位、K1/K2、IP、EP、异或、S-Box、P4、交换和最终置换。

“示例”填入明文 `10011010`、密钥 `1010000010` 并加密，结果是 `11101111`。将该密文填入输入分组，再点击“解密”，结果应为原明文。

修改输入后旧结果被清除，避免将上一次输出误认为新输入的结果。

## 3. ASCII 文本

左侧输入 ASCII 明文，设置 10 位密钥，点击“加密文本”；密文显示在右侧。选择二进制、十六进制或 Base64 时，合法密文自动无损转换。无效密文会阻止转换并保留原格式，便于修正。

解密时粘贴对应格式的密文并点击“解密密文”，恢复文本和逐字节明细显示在下方。三种格式均允许排版空白；二进制长度必须是 8 的倍数，十六进制必须成对，Base64 必须包含正确填充。

空文本合法，结果是零字节。中文、表情或其他非 ASCII 字符会在输入旁提示位置。若错误密钥导致解密结果包含非 ASCII 字节，界面提示核对密钥，仍保留完整字节明细，不丢弃无法解码的字节。

Qt 文本编辑器会将输入换行规范化为 LF；需要逐字节保留 CRLF 或全部控制字节时，开发接口的 `encrypt_bytes` / `decrypt_bytes` 可直接处理原始 bytes。

## 4. 暴力破解

表格每行是一组 8 位明文和 8 位密文，不显示单独的行号栏。双击单元格或按 F2 编辑；“添加一行”追加行，“删除选中”删除选择。

点击“开始搜索”枚举 0～1023，列出满足**全部**已知对的密钥。结果顶部显示候选数、已检查数量和真实计算耗时。“取消”采取协作停止，部分结果标为“未完成”；候选 CSV 包含完成状态、已检查数量及耗时。

当前累计移位 1、2 位的规则存在等效密钥。两个密钥若仅原始第 2 位不同，会生成同一对子密钥；因此候选集合不保证能缩小到一个，不能据此宣布找到了唯一原始密钥。

## 5. 封闭测试

输入指定明文，点击“开始分析”。默认遍历它对应的全部密钥；勾选“遍历全部 256 种明文”会执行 262144 次加密。

顶部数字是指定明文的不同密文数、碰撞组数及最大候选数，耗时是整个任务的计算耗时。切换“明文统计”“密钥分组”页签查看两类结果。长密钥列表自动换行，也可悬停查看或“导出密钥映射”。指定明文优先计算；取消后只保留已经完成的分组和统计。

固定明文时，1024 个密钥映射到最多 256 个密文，必有碰撞。某个具体密文的候选数由实测决定，并非总是 4。

## 6. 自检与交叉测试

“测试与说明”页可以运行手算样例自检；勾选全空间验证检查全部加解密往返。完整的格式、服务和 UI 测试请运行 `python -m unittest discover -v`。

“导出样例”输出 8 条数据；“导入并验证”同时检查加密与解密是否和文件相符。UTF-8 文件允许 BOM，表头必须为：

```csv
plaintext,key,ciphertext
10011010,1010000010,11101111
```

三列均为二进制字符串，宽度依次是 8、10、8。作为文本交换文件，保留前导零。格式错误或结果不符会逐行标明；文件读取失败会显示原因。其他小组文件的列顺序不同时，保留原文件，另存一份按上述顺序排列的导入文件，保持位串和数据行顺序一致。

交叉测试使用另一小组的测试向量，同时比较加密结果和解密恢复结果。实验数据、逐行结果与截图见[组间交叉测试报告](cross-test-record.md)，导入 `docs/evidence/cross-test/peer-vectors-import.csv` 可复现实验。本地导出的 8 条样例用于检验 CSV 交换功能。参数与规则位于页面底部的“展开算法参数与说明”。

## 7. 动效与任务状态

加载反馈至少显示 **600 ms**，期间窗口仍可操作。服务计算提前结束时显示“结果就绪”；最短反馈结束后呈现结果。内容展开和进度缓动为 **180 ms**，页面切换即时重绘。程序显示的计算耗时来自服务计时，不包含界面展示等待。

取消、异常和关闭窗口不会被最短时长拖延；已经完成的计算仍如实显示为完成。Windows 关闭客户端动画时，程序使用静态加载标记和即时更新，也可显式设置：

```powershell
$env:SDES_REDUCED_MOTION = "1"
python -m sdes_app
```

设置为 `0` 强制启用，删除该环境变量后恢复跟随系统。见 [动效与组件说明](ui-design.md)。

关闭窗口时，如有后台任务，程序先请求取消，待线程退出后再关闭。无需手动终止进程。
