# 界面与动效约定

## 视觉层级

浅灰蓝画布、白色分区、蓝色主操作。分区通过留白区分，不叠加外框。二进制输入与结果并排，说明提示为常规小字号，仅实际位串使用大号等宽字体。轮密钥紧随结果；破解和封闭测试用数值摘要显示重点。

输入框使用浅底色，鼠标点击以颜色变化反馈。Tab 导航保留轻量焦点提示，表格通过选中行的侧边标记提示键盘焦点。输入错误直接显示。

## 统一表格

所有表格采用浅色表头、横向分隔线和统一留白，无左侧行号栏和纵向密集网格。表头为 42 个逻辑像素，基础行高 44；长文本自动换行并增高。位串及数值居中，长密钥列表左对齐。空表显示“暂无数据”。

列宽先满足内容的最小宽度，再按比例分配余量；较窄窗口中的交叉表使用横向滚动，保留完整位串。表格高度按完整行计算，超出可见行数时内部滚动；纵向轨道从表体开始，横向滚动条位于底部，不侵占表头和数据行。

碰撞页用“明文统计”“密钥分组”页签呈现两个数据集，页签包含数据行数，同一时刻显示一个表格。表格布局由一个共享控制器管理，数据模型就地更新，不反复创建。

下拉选项沿用浅底、蓝色选中、圆角的控件风格。通用格式规则放在悬停提示和可访问描述中，算法细节默认收起；错误、任务状态和关键结果直接显示。

## 时间与状态

| 动效 | 时长 | 实现 |
|---|---|---|
| 加载反馈 | 最短 600 ms | 成功任务不足时由 UI QTimer 补足，计算线程无延时 |
| 页面切换 | 即时 | 原生控件直接重绘，减少表头叠影 |
| 参考说明与计算步骤 | 180 ms | 高度缓动；快速展开或收起从当前高度继续 |
| 进度更新 | 180 ms | OutCubic 缓动，成功完成时准确归位 |
| 加载指示器 | 1000 ms / 圈 | 抗锯齿圆弧，16 ms 更新间隔 |

计算进行时显示“计算中”；计算结束但处于最短反馈阶段时显示“结果就绪”；随后显示结果。服务层 `elapsed` 始终为实际计算时间，不计入 UI 等待。异常和取消立即结束反馈；关闭窗口跳过展示等待，但仍等待真实计算线程安全退出。

Windows 客户区动画关闭时，使用静态加载标记、即时页面/内容/进度更新，不等待最短展示时间。`SDES_REDUCED_MOTION=1` 强制简化，`0` 强制启用，未设置则跟随系统。系统偏好通过只读的 [SystemParametersInfoW / SPI_GETCLIENTAREAANIMATION](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-systemparametersinfow) 查询。

## 组件与验证

主题位于 [sdes_app/ui/theme.py](../sdes_app/ui/theme.py)；焦点和动效策略分别位于 [sdes_app/ui/focus.py](../sdes_app/ui/focus.py)、[sdes_app/ui/motion.py](../sdes_app/ui/motion.py)。共享表格、选项、摘要、展开区域和任务组件位于 [sdes_app/ui/widgets](../sdes_app/ui/widgets/)。页面保持独立小文件，算法和服务不依赖动效代码。

自动验证包括最短展示期间 Qt 事件循环响应、实际耗时不变、取消/关闭/异常/重新启动、快速切换及键盘导航。截图覆盖 1120 × 900 与 880 × 600；[实验材料索引](evidence/README.md)包含下拉选项、展开状态与实际 Qt 帧加载预览。

另外在独立 Qt 进程中验证 150% / 200% 缩放下的完整行、最小列宽、长文本换行、末行滚动、滚动轨道与页面切换后的表头像素，保存 150% 缩放的离屏截图。

## 应用图标

蓝色圆角底、白色盾形与两个交错的分组方块，表示分组密码与保护。图标不含字母或文字。

![图标](../sdes_app/ui/assets/app.png)

SVG 为唯一设计源，PNG 用于预览，ICO 包含 16、24、32、48、64、128、256 像素版本。应用与主窗口均设置该图标，随源码包分发。使用 `python tools/export_icon.py` 从 SVG 更新导出资源，需要可选 Pillow 依赖。
