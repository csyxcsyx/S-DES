# 暴力破解录像操作步骤

这份文档提供录制步骤，尚未录制真实桌面视频。报告中的截图来自实际 Qt 控件渲染，不能替代题目要求的视频或动图。

## 准备

1. 在项目根目录运行 `python -m sdes_app`。
2. 打开“暴力破解”页，保留默认明文 `10011010` 和密文 `11101111`。
3. 开始屏幕录制，可使用已有录屏工具。Windows 游戏栏可先按 Win+G 确认录制入口，使用 Win+Alt+R 开始或结束可用应用的录制。

## 连续演示

1. 保持录制，说明已知一组明密文，未知密钥需要枚举 1024 种可能。
2. 点击“开始搜索”。加载反馈至少展示 600 ms；提前算完时显示“结果就绪”。镜头保留结果区域，可看到候选数、已检查 1024 个密钥和独立记录的真实计算耗时。
3. 展示候选 `1010000010` 与 `1110000010`。说明累计移位 1、2 位遗漏原始密钥第 2 位，二者生成相同轮密钥。
4. 添加第二组：明文 `01010101`、密文 `00000101`，再次搜索。两个等效密钥仍会保留。
5. 导出候选 CSV，展示文件包含候选、完成状态、已检查数量与真实耗时。
6. 如需演示取消，切换到“封闭测试”，勾选全部明文，开始后点击取消。速度较快时也可能已经完成；如已完成应如实保留，不伪造取消画面。
7. 结束录制，检查视频能够看到按钮点击和最终结果；将视频文件或可访问链接补入提交材料。
